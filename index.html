Part 1.1

Convolutions from Scratch

A 2D convolution implemented with numpy only: first with four nested loops, then with two, both using zero padding and a flipped kernel. The results are compared against scipy.signal.convolve2d.

Four-Loop Implementation

for y in range(h):
    for x in range(w):
        for ky in range(kh):
            for kx in range(kw):
                output[y, x] += (padded[y + ky, x + kx] * kernel[ky, kx])

Two-Loop Implementation

for y in range(h):
    for x in range(w):
        window = padded[y:y + kh, x:x + kw]
        output[y, x] = np.sum(window * kernel_flipped)

Comparison with SciPy

ImplementationRuntime (seconds)
Four loops (numpy)174.02
Two loops (numpy)13.97
scipy.signal.convolve2d0.51

The two-loop implementation is faster than the four-loop implementation because it processes an entire image patch at once instead of multiplying each kernel element one by one. The scipy.signal.convolve2d implementation is the fastest because it uses cache. The outputs from my implementations match the SciPy result aside from possible very small floating-point differences. For boundary handling, both of my implementations use zero-padding so that the output has the same size as the input image.

Results — Box Filter and Finite Differences

A grayscale photo of myself convolved with a 9×9 box filter and with the finite difference operators Dx and Dy.

Here, we can see that the four-loop and two-loop implementations produce the same blurred result. The Dx filter highlights intensity changes in the x-direction, which emphasizes vertical edges. The Dy filter highlights intensity changes in the y-direction, so it emphasizes horizontal edges.

Part 1.2

Finite Difference Operator

The cameraman image is convolved with Dx and Dy to get its partial derivatives, which are combined into the gradient magnitude

‖∇I‖ = √(∂I/∂x)2 + (∂I/∂y)2

and then binarized with a threshold to produce an edge image.

Partial Derivatives and Gradient Magnitude

Choosing the Threshold

I tried several thresholds and chose 0.1 for the final edge image.

I chose a threshold of 0.1 because it preserves more of the real edges in the background buildings while removing many of the noisy edges caused by the grass. Lower thresholds keep more weak edges but also introduce more noise, while higher thresholds suppress more noise but can remove some real edges.

Part 1.3

Derivative of Gaussian (DoG) Filter

The finite difference results are noisy, so the image is first smoothed with a Gaussian filter built from cv2.getGaussianKernel and its outer product. The same edge pipeline is then repeated, first as two convolutions (blur, then differentiate) and then as a single convolution with derivative of Gaussian filters.

Gaussian Smoothing, then Finite Differences

Compared with the finite difference results in Part 1.2, the Gaussian-smoothed result preserves the important background edges while reducing many of the noisy edges caused by the grass.

Derivative of Gaussian Filters

Convolving the Gaussian with Dx and Dy gives two DoG filters, shown here as images.

Single Convolution with DoG Filters

We can see that the single-convolution DoG result matches the two-step result. This is because convolution is associative, so convolving the image with the Gaussian and then the derivative filter is mathematically equivalent to first convolving the Gaussian with the derivative filter and then applying the resulting DoG filter to the image.

Part 2  Applications Sharpening Hybrid Images Stacks Blending

Part 2.1

Image "Sharpening"

A Gaussian filter keeps only the low frequencies of an image, so subtracting the blurred image from the original leaves the high frequencies. Adding a scaled copy of those high frequencies back makes the image look sharper.

Taj Mahal

As α increases, the image becomes progressively sharper because the high-frequency details are amplified more strongly. However, very large values of α can also make edges look overly strong or unnatural.

My Own Image

Blur, then Re-Sharpen

For evaluation, a sharp image is blurred and then sharpened again to see how much of the original detail comes back.

We can observe that sharpening cannot completely recover the original sharp image because some information is permanently lost during the blurring process. Increasing α can make the blurred image appear sharper, but it cannot fully reconstruct the fine details that were removed.

Part 2.3

Gaussian and Laplacian Stacks

A stack is like a pyramid without the downsampling: every level keeps the original image size. Each level of the Gaussian stack is a further-blurred copy of the previous one, and each level of the Laplacian stack is the difference between two consecutive Gaussian levels, with the last level holding the remaining low frequencies.

I used 5 levels with an initial σ = 1. I doubled σ at each level to create progressively stronger blur, giving σ = 1, 2, 4, 8, and 16. The Gaussian kernel size was chosen as 6σ + 1, resulting in kernel sizes of 7×7, 13×13, 25×25, 49×49, and 97×97.

Part 2.4

Multiresolution Blending

Following Burt and Adelson (1983), two images are blended by combining their Laplacian stacks level by level, weighted by a Gaussian stack of the mask, and then summing the levels. Because the mask is blurrier at coarser levels, low frequencies transition gradually while fine details keep a tight seam.

The Most Important Thing I Learned

The most important thing I learned from this project is that image blending is more difficult than it first appears. A good result depends on many factors, including image size, alignment, and the design of the mask. I especially found that creating a mask that follows a natural boundary in the image can make a large difference in how seamless the final blend looks.
